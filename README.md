# Arabic Cryptocurrency Wallet

محفظة عملات مشفرة عربية داخل Telegram Mini App.

## Stack
- Next.js for the Telegram Mini App
- NestJS API
- PostgreSQL + Prisma
- BNB Chain + Polygon
- Non-custodial embedded wallet

## Getting started
1. Copy `.env.example` to `.env`
2. Install dependencies with `pnpm install`
3. Run the apps with `pnpm dev`
